## 🚀 Featured Projects

### 🗂️ [Karya](https://github.com/dharamveersahu18/Karya) (formerly TaskForge)

A team project management platform where teams create projects, add members, assign tasks and track progress.

- Task management with priorities, statuses, deadlines and assignments
- Authentication and authorization for users, project owners and team members
- RESTful APIs built with Node.js and Express, backed by MongoDB

**Stack:** React · Tailwind CSS · Node.js · Express · MongoDB
**Links:** [Source code](https://github.com/dharamveersahu18/Karya)

### 📝 [NexusPost](https://github.com/dharamveersahu18/Blog)

A full-stack blogging platform where users can create, edit, publish and manage posts.

- Authentication and authorization for user-specific content and actions
- Likes, view counters and cloud image storage
- Appwrite for the database, authentication and file storage; responsive layouts for mobile

**Stack:** React · Tailwind CSS · Appwrite · JavaScript
**Links:** [Live demo](https://nexuspost.web.app/) · [Source code](https://github.com/dharamveersahu18/Blog)

### 🔴 Redis Leaderboard and Real-Time Notifications (practice project)

A hands-on project for learning Redis through a leaderboard and a notification flow.

- Leaderboard using Redis Sorted Sets to store and rank player scores
- Explored Pub/Sub for real-time notifications and Streams for event production and consumption

**Stack:** Redis · Node.js · Express · JavaScript
